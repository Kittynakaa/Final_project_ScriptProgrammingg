## 2. บันทึก Prompt และการตรวจสอบของทีม

### 🔹 Prompt 1 — ประเมินโทนผิวด้วย ITA
- **คำถามที่ใช้:**
  ```text
  อธิบายวิธีวัดโทนผิว (undertone) จากภาพด้วยค่า ITA ใน CIE Lab color space
  และช่วงค่าที่ใช้แบ่ง cool / warm / neutral
  ```
- **สรุปคำตอบจาก AI:** ITA = atan2(L*−50, b*) หน่วยองศา; L* คือความสว่าง,
  b* คือแกนเหลือง–น้ำเงิน; ค่ามากเอียงไปโทนสว่าง/เย็น ค่าน้อยเอียงอุ่น
- **ทีมทำต่อ/ตรวจสอบเอง:** ทดสอบกับรูปจริงหลายรูป ปรับเกณฑ์ตัดสินให้เหมาะกับ
  ชุดข้อมูลของเรา และเขียน unit test `test_classify_ita_*` ยืนยันการแบ่งช่วง

### 🔹 Prompt 2 — ตรวจจับบริเวณผิว (skin mask)
- **คำถามที่ใช้:**
  ```text
  วิธีทำ skin detection ด้วย OpenCV แบบง่ายด้วย YCrCb threshold และทำความสะอาด
  mask ด้วย morphology พร้อมเลือกก้อนที่ใหญ่ที่สุด
  ```
- **สรุปคำตอบจาก AI:** ใช้ `cv.inRange` บนช่วง Cr,Cb ของผิว, `morphologyEx`
  (OPEN/CLOSE) ลบ noise, และ `connectedComponentsWithStats` เลือก component
  ที่พื้นที่มากสุด
- **ทีมทำต่อ/ตรวจสอบเอง:** เพิ่มกรณีพิกเซลผิวน้อยเกินไป → คืน `unknown` แทนการ
  เดามั่ว และเขียนเทสต์ `test_undertone_unknown_when_no_skin`

### 🔹 Prompt 3 — ออกแบบสถาปัตยกรรม OOP 3 เลเยอร์
- **คำถามที่ใช้:**
  ```text
  ช่วยออกแบบโครงคลาสแบบ OOP แยก Presentation / Business Logic / Data Access
  สำหรับระบบวิเคราะห์ภาพและแนะนำสี
  ```
- **สรุปคำตอบจาก AI:** เสนอ `NailApp` (CLI), `SkinAnalyzer` + `NailRecommender`
  (logic), `DataStore` + `PaletteRenderer` (data/render) และโมเดล `Suggestion`
- **ทีมทำต่อ/ตรวจสอบเอง:** นำมาปรับให้กฎเป็น data-driven (โหลดจาก JSON), เขียน
  โค้ดจริงและรันทดสอบครบทุกโมดูล

### 🔹 Prompt 4 — จัดการข้อผิดพลาด (Exception Handling)
- **คำถามที่ใช้:**
  ```text
  ควรดักข้อผิดพลาดอะไรบ้างในโปรแกรม CLI ที่อ่านรูปจากไฟล์
  ```
- **สรุปคำตอบจาก AI:** ตรวจไฟล์มีจริง, `cv.imread` คืน None เมื่อไม่ใช่รูป,
  ครอบ `KeyboardInterrupt`/`EOFError` เพื่อปิดโปรแกรมอย่างสุภาพ
- **ทีมทำต่อ/ตรวจสอบเอง:** ทดสอบด้วย path ที่ไม่มีจริงและไฟล์ที่ไม่ใช่รูป ยืนยัน
  ว่าไม่ crash

## 3. หลักการใช้ AI อย่างรับผิดชอบของทีม (Responsible AI Principles)

- ใช้ AI เป็น "ผู้ช่วยเรียนรู้" ไม่ใช่ "ผู้เขียนแทน" — ทุกโค้ดทีมเข้าใจและอธิบายได้
- ตรวจสอบความถูกต้องของคำตอบเสมอ (โดยเฉพาะสูตร/ตรรกะ) ด้วยการรันและเขียนเทสต์
- อ้างอิงที่มาความรู้ (color science, OpenCV docs) และไม่นำข้อมูลลับ/ส่วนตัวเข้า prompt
